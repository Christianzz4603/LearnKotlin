Learning paths

1

Absolute beginner

Start here on this site: Getting Started → Install → Coding. Then follow the official Getting started tutorial.

2

Coming from Java

Read Comparison to Java and the Java interop docs. Most of your existing knowledge transfers directly.

3

Android developer

Use Android Studio’s Kotlin templates and the Android Kotlin guides. Jetpack and Compose are Kotlin-first.

4

Backend / server

Explore Ktor, Spring Boot with Kotlin, or Exposed for databases. The standard library and coroutines shine on the JVM.
